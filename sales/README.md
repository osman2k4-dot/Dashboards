# Sales kit — Project Progress Dashboard template

Everything needed to list and promote `template-project-progress-dashboard.html` as a paid product.

| File | Use it for |
|---|---|
| `three-hour-launch-plan.md` | Step-by-step plan for the first 3 hours |
| `gumroad-listing.md` | Product title, description, price, FAQ to paste into Gumroad / Lemon Squeezy / Etsy |
| `linkedin-post.md` | Launch post + 3 follow-up posts |
| `freelance-gig.md` | Upwork / Fiverr gig description and three price tiers |
| `cold-dm.md` | Short messages to planners, PMs and site managers you already know |

Host the demos free on GitHub Pages (repo Settings → Pages → branch `main`, root). The live URL becomes the portfolio link in every listing.
