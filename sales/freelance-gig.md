# Upwork / Fiverr gig

## Title
I will build a single-file HTML progress dashboard from your construction project's Excel data

## Category
Data → Data Visualization (Fiverr) / Data Analytics & Visualization (Upwork)

## Description

Your project reports weekly in Excel and PowerPoint. I turn that into an interactive, single-file HTML dashboard that updates itself from your sheet.

**What you get**
- One HTML file that opens in any browser, on any device, offline, with no licence or server.
- S-curve (planned vs actual), SPI and schedule variance, forecast finish, weekly progress, activity status table, manpower, concerns list.
- Your logo, colours and project name.
- An Excel workbook structured so your team can refresh the dashboard by dropping the file back in. No rebuild needed.

**Why me**
Project controls professional on a live oil and gas EPC site. These dashboards run there daily: piping progress mapped on the plot plan, steel erection by unit, welder and crane productivity, scaffolding, E&I, civil works. See the demo portfolio: [portfolio link]

**How it works**
1. You send a sample of your weekly report or Excel data (dummy numbers are fine).
2. I map it to the dashboard and send a first version in 2 to 3 days.
3. One round of revisions, then delivery with a 1-page guide.
