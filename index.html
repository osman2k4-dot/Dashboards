How these work

Each dashboard is one self-contained HTML file. Site data (daily reports, Excel registers, P6 exports) is processed into embedded JSON, charts render with Chart.js, and the file can be emailed, opened offline, or dropped on a shared drive. Several accept a fresh Excel drop to refresh themselves — no rebuild needed. If your project runs on Excel exports and PowerPoint decks, this is the upgrade path.
